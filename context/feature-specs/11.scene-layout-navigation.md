# 11 · Scene Layout & Navigation

## Goal
Show all of a project's scenes on one scrollable page and navigate by
scrolling, and make "Add Scene" an instant client-side action that only
persists when the user generates.

## Current behavior
- `editor/[projectId]/page.tsx` renders only the `?scene=<id>` scene;
  sidebar entries switch scenes via that query param.
- "Add Scene" in `editor-sidebar.tsx` persists immediately via
  `createScene` and then navigates to the new scene.

## Requirements

### 1. Render all scenes, scroll to navigate
- The project page renders every scene stacked vertically.
  No pagination — show all scenes.
- Each scene card carries an anchor id (e.g. `scene-<id>`).
- Clicking "Scene #N" in the sidebar smooth-scrolls to that card,
  like clicking `url.com/#section`. No page/query navigation.
- Remove the existing `?scene=`-based scene navigation.

### 2. Temporary (optimistic) "Add Scene"
- Clicking "Add Scene" appends a new blank scene card client-side
  for instant UI feedback — no DB write.
- The scene persists to the DB only when the user hits Generate on it.
- Refreshing before generating discards the temporary scene.

## Out of scope
- Pagination, scene reordering, and scene deletion.
